# 3DMEAD and UniTalker data-license boundary

- Retrieved: 2026-08-13
- 3DMEAD code repository: https://github.com/wangxuanx/Face-Diffusion-Model
- UniTalker code repository: https://github.com/X-niper/UniTalker

Both repositories publish code under Apache-2.0. That license applies to repository code and does
not establish rights for the datasets linked or repackaged by the repositories.

The 3DMEAD README states that MEAD was reconstructed with EMOCA and provides a separate Baidu
download, but it does not attach a dataset-specific license in the README. Using 3DMEAD therefore
requires verification of the original MEAD terms, EMOCA/FLAME-related rights as applicable, and
the derived release terms.

The UniTalker README links an aggregate data release containing BIWI, VOCASET, MeshTalk, 3DETF,
HDTF, RAVDESS, FaceForensics++, Chinese speech, and song subsets. Its repository Apache license
must not be applied to those upstream datasets. Each component needs its own rights profile and
`source_id`; a single aggregate rights profile is prohibited.

Project classification for both data releases remains `unverified/block` until all upstream
evidence is saved and reviewed.
